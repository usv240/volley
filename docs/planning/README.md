checked against them. They describe gates, dates and intentions as they
stood when written; some were met, some were changed by what the device
did, and one (a practitioner's sentence) was dropped by design: no real
people are involved in this entry.

What is true now, with evidence a reviewer can check, is in
[../FOR_JUDGES.md](../FOR_JUDGES.md).

waiting and reads the roles from the transcript instead, measured on
